# BitRushJS
A lightweight endless runner game developed in vanilla JavaScript, featuring smooth animations, collision detection, and infinite terrain generation.

---
## 🎮 Features

- 🐶 Smooth sprite-based dog animation  
- 🌌 Endless world generation  
- ⚡ Frame-by-frame motion control  
- 🕹️ Keyboard-controlled gameplay  
- 💻 100% Vanilla JavaScript + HTML + CSS  

---

## 🚀 How to Play

- **Spacebar / ↑ Arrow** → Jump  
- **Avoid** obstacles to survive longer  
- **Score** increases with time — test your reflexes!
